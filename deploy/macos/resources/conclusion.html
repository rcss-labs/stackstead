Stackstead is installed

Open http://127.0.0.1:8420 in your browser to create the admin account.

If nobody was logged in at this Mac during the installation, set up the service for a user with:

sudo /usr/local/share/stackstead/install.sh --from-pkg --user NAME

Logs are in ~/Library/Logs/Stackstead/stackstead.log. To remove Stackstead (your configuration, data and stacks are kept):

sudo /usr/local/share/stackstead/install.sh --uninstall

About the security prompt

This package is not signed with an Apple Developer ID. If macOS says it is from an unidentified developer, right-click the package and choose Open, or install it from a terminal with sudo installer -pkg stackstead_<version>_darwin.pkg -target /. The installed program runs normally.
