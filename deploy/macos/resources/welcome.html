Stackstead

A small web UI and API for managing Docker Compose stacks.

This installer puts the stackstead command in /usr/local/bin and sets up a per-user background service (a LaunchAgent) for the user who is logged in at this Mac. It never touches your Docker containers, and it never changes an existing configuration, database or stacks directory.

Docker Desktop, OrbStack or Colima must be installed and running for stacks to work.
