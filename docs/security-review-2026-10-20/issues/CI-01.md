## Proposed work

Add least-privilege PR CI for existing checks, appropriate dependency/security scanning and a patched compiler policy. Pin external actions; avoid exposing secrets to fork code. Configure required checks/branch rules deliberately. Provide runnable tagged integration/installer jobs where infrastructure supports them; otherwise document an explicit deferred/manual execution policy, including prerequisites and when those checks must run.

## Acceptance criteria

- [ ] Run the existing `make check` on pull requests and enforce it as a required check under the selected branch policy.
- [ ] Provide runnable tagged integration/installer jobs where infrastructure supports them; otherwise define an explicit deferred/manual execution policy with prerequisites and required execution points.
- [ ] A passing change completes the required workflow; a meaningful failing check blocks merge under the selected branch policy.
- [ ] Verify permissions and fork behavior; validate actual GitHub rule/check enforcement, not just workflow presence.
- [ ] Keep Docker/systemd/installer checks in suitable separate environments rather than representing unit checks as equivalent.
