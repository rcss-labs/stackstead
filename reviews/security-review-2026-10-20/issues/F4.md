## Problem and impact

Every five-second tick increments the request generation. If each response takes six seconds, the next request invalidates the previous result before completion; the screen can stay loading/stale while requests overlap.

Priority: **P2**.

## Proposed work

Skip a tick while loading or schedule the next poll after completion. Preserve generation invalidation for stopped/restarted controllers.

- [ ] Assert bounded concurrent requests, stop/restart invalidation and cleanup; run fleet/controller tests.
