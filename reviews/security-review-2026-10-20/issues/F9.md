## Problem and impact

The script creates a high-precedence /etc/systemd/system unit pointing to /usr/local/bin, while packages install a lower-precedence /usr/lib/systemd/system unit and /usr/bin binary. Installing a package over a script install can leave the old binary running while package installation appears successful. This was traced statically, not reproduced on systemd.

Priority: **P2**.
